# family-management-tool

家庭の支出・家事タスク・子供の予定・家族旅行をまとめて管理するツールです。

## 特徴

- サーバー・ビルド不要。`index.html` をブラウザで開くだけで使えます
- データはブラウザの localStorage に保存されます(端末外には送信されません)
- 4つの機能をタブで管理します
  - 💰 支出管理(家計簿): 日付・金額・カテゴリ・支払者を記録し、月別/カテゴリ別に集計
  - 🧹 家事タスク: 担当者・頻度(毎日/毎週/毎月/一回限り)を設定し、完了チェックで繰り返しタスクを自動再生成
  - 📅 子供の予定: 日時・場所・メモを記録し、今後/過去の予定を一覧表示
  - ✈️ 家族旅行: 旅行計画と持ち物・準備チェックリストを管理
- 家族メンバー(名前・色)を登録し、各記録に紐づけられます

## 使い方

`index.html` をブラウザ(Chrome/Safari/Edge等)で直接開いてください。

ローカルサーバー経由で開く場合の例:

```
python3 -m http.server 8000
# http://localhost:8000/index.html を開く
```

## データについて

すべてのデータはブラウザの localStorage に保存されます。別の端末やブラウザとは共有されません。
バックアップが必要な場合はブラウザの開発者ツールから `localStorage["familyToolData"]` の内容をエクスポートしてください。
